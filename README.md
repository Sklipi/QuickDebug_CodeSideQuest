# QuickDebug_CodeSideQuest
little school project with a cool idea that came to me at like 5am

basically its a coding sidequest website that uses gemini api to generate short coding missions for you...upon completion you can submit the code
and the AI will review it and deem if the quest was achieved or not, rewarding you with xp that you use to level up.

it also got a debugging tool that also uses Gemini to review lines of code for any error and that returns the correct solution and even
proposes better solutions

--------------------------------FEATURES-------------------------------------------------------------------------------------------
quest generation
xp and level up system
login system (local storage for now) to keep track of progress
leaderboard
completed quest counter

debuggin tool that reviews and corrects mistakes in code

future features will be tought about and added
